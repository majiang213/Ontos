# 整理布局按线排：连线的对象左右分列，两端水平对齐，路由当验收器

「整理布局」按 dagre 从左到右分层，边从目标指向来源，被引用的对象在左。一条边的两端尽量排在同一条水平线上；同一列里连向不同对象的卡片上下错开。一张很高的卡片只拉高自己那一列，不再把后面所有对象整行推到它脚下。没有连线的对象用天际线排到连线部分的右侧，不垫在下面。

把一层排成横行、行高取该行最高卡片，会让图的高度等于每层最高卡片之和。屏幕是横的，图一拉高，取景就把所有卡片缩得很小。左右分列把高度留给最高的那一列，宽度留给列数。

**排完用现有路由当验收器。** 逐边看直接曲线会不会穿进别的节点。还有穿过的，就加宽列距再排；加宽不再减少穿过的边就停，不把图空撑大。到上限仍有穿过的，接受当前结果——路由本身兜底（A* 保证不穿节点），加宽只为提高取直率。

**相邻两列的间距还要放下这条边上的说明。** 说明画在线的中点。两张卡片之间的缝窄于说明时，说明会被推到线外的空处。整理布局按说明的宽度把这一道缝拉开，两侧各留一点，说明就留在线上。短说明仍用基本列距。跨过中间列的边不加这个间距。

**渲染层小修三项。** 贝塞尔采样按曲线长度自适应加密（24 个定值点对长边会漏检节点角，"0 穿节点"的验证要可信）；线标签查节点碰撞，压到就在线身两侧找净位置（先沿法线推档、再沿切向让位，`labelPushOf` 一处纯函数），实在找不到才退回原位。

**整理布局清掉弯折与钉点。** 弯折存的是相对两节点中点的偏移、钉点存的是相对边框的比例，重排后旧几何全部失效，保留任何手工痕迹都可能产生怪异线形。整理布局的语义就是回到干净状态：线恢复浮动附着，真在意的人重排后再钉。

**未摆位新节点与整理布局共用同一份计算。** 新对象上画布时已存摆位留在原位、新节点按算出的位置落位，与整理布局同算法（AGENTS.md 既有纪律，不另开两套）。计算从 `initialNodes` 的 memo 里拆出独立 memo——原依赖里混着悬停态，升级成迭代算法后会随悬停全量重算。

**验收判据（可测）。** 0 条线穿节点是硬保证（路由保证 + 采样加密让验证可信）。相邻列的边取直（枢纽图、长链全是直接曲线）。跨过中间列的边可以绕行，不为它们把列距撑开。确定性（同输入同输出）。验证图集 = 无连线 / 部分连线 / 枢纽 / 长链 / 带跨列边的密集图。
