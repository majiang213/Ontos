# 整理布局按线排：有连线的图一层一行不折行，路由当验收器，取直率 ≥ 80% 才算过

「整理布局」过去只算节点位置（dagre 分层 + 按列折行），完全不知道线的存在。渲染层虽有绕障兜底（默认直接贝塞尔，采样撞节点才退 A* 正交绕障），但布局几何对线不友好：折行把跨层长边拦腰掰断、层距窄、线标签不查节点碰撞、长贝塞尔只采样 24 点会漏检节点角——于是"线被遮盖、线不优雅"成了系统性现象。改法：布局改为按线排，线形态体系（曲线为主、绕不开才正交绕障）不动。

**有连线的图一层一行，不折行。** 折行是长边穿行的元凶——一条跨多层的边会被折行从中间掰断、穿进别的层。层内顺序仍由 dagre 给（它本身已做交叉最小化）。没有连线的孤立对象仍按网格折行：它们没有线，折行无害，且网格是"没线也均匀"的唯一保证。

**层距加宽、给跨层长边留走廊；排完用现有路由当验收器迭代。** 布局产位置后，逐边用 `edgePath` 实际验证：验证不过的边，就地加宽走廊再排，迭代到"0 条边穿节点"。迭代有上限，到上限接受当前结果——路由本身永远兜底（A* 保证不穿节点），迭代只为提高取直率。

**渲染层小修三项。** 贝塞尔采样按曲线长度自适应加密（24 个定值点对长边会漏检节点角，"0 穿节点"的验证要可信）；线标签查节点碰撞，压到就在线身两侧找净位置（先沿法线推档、再沿切向让位，`labelPushOf` 一处纯函数），实在找不到才退回原位。

**整理布局清掉弯折与钉点。** 弯折存的是相对两节点中点的偏移、钉点存的是相对边框的比例，重排后旧几何全部失效，保留任何手工痕迹都可能产生怪异线形。整理布局的语义就是回到干净状态：线恢复浮动附着，真在意的人重排后再钉。

**未摆位新节点与整理布局共用同一份计算。** 新对象上画布时已存摆位留在原位、新节点按算出的位置落位，与整理布局同算法（AGENTS.md 既有纪律，不另开两套）。计算从 `initialNodes` 的 memo 里拆出独立 memo——原依赖里混着悬停态，升级成迭代算法后会随悬停全量重算。

**验收判据（可测）。** 0 条线穿节点是硬保证（路由保证 + 采样加密让验证可信）；取直率 ≥ 80%；0 处标签压节点；交叉数不劣化（观察指标，不当闸门）；确定性（同输入同输出，纯函数纪律）；验证图集 = demo 种子图 + 测试构造图（无连线 / 部分连线 / 全连线 / 长链四种形态）。
