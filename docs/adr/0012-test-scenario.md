# test 空间剧本：设备一生 + 办公线双线交汇（候选对按剧情点名）

> **2026-09-01 修订注记（本体认识纠错，E2/E5/E6/E7）**：①原「10 对候选、四类裁决齐全」违反「对类关系计数的任何说法一律不能用」禁令，分布行删除；②「部分重叠立公共对象」已被 ADR 0013 取代（同一概念的表并成一个多源类）；③概念归纳生成（E3）落地后多数表级候选对不再出现，剧本需按新流程整体重推——按纠错清单决定 5：点检、处置两对保留（行=个体时期本身），保修卡、账号×门禁卡两对改自动建链（身份用 card_id / 自身单号，引用列不做身份）。重推前本清单仅作历史对照。

原 test 空间剧本是三波抽查式案子（第一波物、第二波人、第三波客货），案子互不串、没有一条连贯的业务故事线。重设计后：一条设备主线 + 一条办公支线，在「维修」处交汇（生产设备维修 vs 办公设备 IT 报修），可落地裁决与跳过案按剧情安排（不是结论种类清册）。一场演示 25 分钟左右。

**撤掉 HR 与招聘，办公线全新设计。** 人事系统（hr_sys）、招聘系统（recruit_sys）整个移除（不再播种文件、不连接）；原"人员"线改由办公场景承担：办公账号（oa_sys 现有）+ 门禁卡（新系统 access_sys）+ 办公设备（新系统 it_sys）+ OA 部门（oa_sys 新表）。"人"以账号持有者出现，不引入员工档案表。

**连接并生成对象的 8 个系统**：device_sys、asset_sys、purchase_sys、inspect_sys、repair_sys、it_sys（新）、access_sys（新）、oa_sys（扩表）。客户/销售/仓库/应收四个客货系统保留为原料（不连接、不生成对象、不产生候选对）。新表：it_sys.device（办公设备）、it_sys.ticket（IT 报修单）、access_sys.card_holder（门禁卡）、oa_sys.dept / room / booking / supply / requisition、asset_sys.disposal（处置档案）。

**候选对清单（2026-09-02 按新流程重推；概念归纳生成 + 判定归 Agent + 单一表现形式）：**

生成即归纳概念，对齐判定由 Agent 依证据执行、留痕住 `adj_decision`；下表是 Agent 的判定与落法（结论种类不封口，逐对点名，不数）：

| 候选对 | Agent 的判定与落法 | 证据 |
|---|---|---|
| 设备台账 device × 资产 asset | 同一概念：并成一个多源类 | 序列号重合 40 台；资产 52 行 = 生产 40 + 办公 12 |
| 点检 instrument × 设备台账 device | 同一概念：并入（点检行=被点检设备，时期/视角不同不是概念不同） | 点检 60 中 40 台对上设备 |
| 采购条目 po_item × 设备台账 device | 生命周期（在途→在役）：并成一个对象 + 时期派生 | 重合 40 台是同一个体的两个时期 |
| 处置档案 disposal × 设备台账 device | 生命周期接续（在役→已处置）：并入，时期派生采纳既有 status 加一段（ADR 0014 的多段时期） | 处置 8 行与设备一一对应（行=个体的已处置时期，不是事件） |
| 保修卡 warranty_card × 设备 device | 不比同类（行=凭证）：建 `covered_by` 链，身份取 card_id，卡身 sn 是引用列 | 都有序列号，但行的性质不是设备本身 |
| 采购订单 order × 采购条目 po_item | 跳过（部分与整体，本期不定案；同库两张表也进判定） | 订单含条目 |
| 生产设备 device × 办公设备 it_device | 同形异义（都叫设备，两种东西） | 12/40 重合是转固残留 |
| 维修工单 repair × IT 报修单 it_ticket | 同形异义（都叫维修，两种记录） | 一个管生产设备、一个管办公设备 |
| 办公账号 account × 门禁卡 card_holder | 不比同类（行=挂在账号上的卡）：建 `has_card` 链，身份取 card_no，holder 是引用列 | 35 张卡按 holder 对上账号 |
| 设备台账部门 department × OA 部门 dept | 同形异义（车间 vs 行政组织） | 交集率 0%：两套编码没有交集 |

**问数四波对应故事段**：第一波「设备一生」（概念并类 + 时期三段：在役/在途/SN-40217）；第二波「办公线」（同形异义与 has_card 链：门禁覆盖/外包账号/IT 报修 vs 维修/办公设备数）；第三波「保修与验收」（covered_by 链 + 发布：已处置/保修期内/订单与条目/事件类统计）；验收后动作波（转固 SN-40217、报废、会议室预订、用品领用——每问验证写回源库）。验收主角 SN-40217 的在途→转固剧情线保留。
