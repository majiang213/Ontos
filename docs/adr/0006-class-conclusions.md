# 类与类关系不是封闭清单；还活着的结论写在 class_conclusions

对齐时对候选对的判定，和本体里类与类的关系，是两套清单。专业词：类等价、部分重叠、生命周期、同形异义、子类型。旧称同一、阶段、仅名称相似只作对照。跳过是这次不定的动作，不是一种类与类关系。

还活着的类与类结论写在根列表 `class_conclusions`：一行一次判定，`classes` 数组，没有 `a` / `b`。`kind` 为 `overlap` / `homonym`，预留 `subtype`。部分重叠行必写 `shared`。同形异义一行一次，不传递，不合成一团。类等价写成合并挂多源，生命周期写成派生阶段加转化，都不进此表。部分与整体、不相交本期不定案。

类型级结论不进 `link_types`（那是个体边）。画布是配置的视图：部分重叠的由来虚线、同形异义芯片，都只投影 `class_conclusions`。裁决留痕仍用机器键 `same` / `overlap` / `stage` / `name_similar` / `skip`。
