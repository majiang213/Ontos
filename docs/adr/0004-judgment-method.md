# 判定按三问合成，交集率只答同一批个体

对候选对问三问：是不是同一种事物（Agent 依证据判断；命中大于零为硬线索）、是不是同一批个体（交集率，可沉默）、是不是不同时期（Agent 依证据判断）。入围不要求不同库、不要求结构相似；同一库两张表也可以比。结构比对只召回。命中大于零则数据不支持同形异义；命中为零则数据不支持部分重叠。同一种、有交集又不是全交、不是时期时，结论可以是类等价或部分重叠；两者都按 ADR 0013 落为同一概念的多源类，来源覆盖面差异不是结构分支。类等价不要求现在是同一批个体。个体在源里一行一个或一列一个，不改变类等价的定义；本期交集率只落地行存。ADR 0003 所说「办法尚未设计」由本条补上。
