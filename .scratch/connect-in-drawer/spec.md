# 连接数据源搬进数据源抽屉（源管理器）

**问题**：工具条上的「连接数据源」与待确认 / 发布 / 验收问题集不是一类——它接的是原料，不是关卡。搬进表结构抽屉后，两类按钮是否各归各位、流程是否更顺？

**结论（2026-08-31）**：采纳 **B · 源管理器**。抽屉两栏：左栏管源（已接入的源点选切换、演示文件一按接入、手动填只读连接），右栏按选中源看表结构并勾选生成。工具条去掉「连接数据源」，只剩任务按钮；左下开关改名「数据源」。

三变体原型（A 抽屉接入条 / B 源管理器 / C 起步即抽屉，`?variant=` 切换 + 底部切换条）完整保留在分支 `proto/connect-in-drawer`，可切分支回看。A / C 落选：A 的源栏叠在表结构内容之上，空空间的「接入」入口不够立得住；C 的空空间自动开抽屉在已开工的空间里多余，且开关与源栏收起按钮双「收起」视觉重复。

**连带修复**：抽屉开着时，左下开关抬到抽屉上沿之上——float-card（z20）原本直接压在 drawer（z15）内容上，抽屉左下角的可点元素会被它拦住（原型期间连接表单的提交按钮就被挡过）。

原型由 `/prototype`（UI 分支）产出，浏览器实测：A 走通接入 → 勾表 → 真模型生成对象全链路；B 实测一键接入与源切换；C 实测空空间自动开抽屉；移动端 375×812 可用；全量测试通过。
