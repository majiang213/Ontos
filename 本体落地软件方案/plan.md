# Plan：通用 Ontology 平台产品与技术架构设计文档

## 目标
为用户产出一份完整的产品与技术架构设计文档（.md → .docx），覆盖：
- 产品定位与核心价值（通用 Ontology 平台：数据建模 + 现有系统改造）
- 元模型设计（对象/属性/关系/动作/规则）
- 三大子系统：建模工作台 Studio、连接与映射引擎 Connect、本体运行时 Runtime
- 现有系统改造的三种接入模式
- Agent 层设计（AI 辅助建模、自然语言问数、Action 执行）
- 竞品格局与差异化（Palantir Foundry、知识图谱厂商、语义层工具）
- MVP 路线与实施风险

## Stage 1 — 调研验证（deep-research-swarm 思路，轻量）
- 并行 explore 子代理：
  1. Palantir Foundry Ontology / AIP 架构事实核查（公开资料）
  2. 竞品扫描：知识图谱平台、语义层、本体工程工具（国内外）
- 输出：调研简报（含可引用来源）

## Stage 2 — 写作（report-writing skill）
- 加载 report-writing skill，按其流程设计大纲并分章写作
- 输入：Stage 1 简报 + 对话中已确立的架构设计
- 输出：/mnt/agents/output/通用Ontology平台产品与技术架构设计.md

## Stage 3 — 格式转换（docx skill）
- 加载 docx skill，将 .md 转为排版良好的 .docx
- 输出：/mnt/agents/output/通用Ontology平台产品与技术架构设计.docx
